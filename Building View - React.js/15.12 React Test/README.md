# 15.12 React Testing

This section covers React Testing Library and Vitest, learning how to write unit tests and integration tests for React components.

## Projects

### testing-practice

A practice project cloned from the Net Ninja React Testing Library tutorial, available at https://github.com/harblaith7/React-Testing-Library-Net-Ninja. This was used as part of the Springboard learning curriculum to get familiar with testing concepts like rendering components, querying elements, simulating user events, and mocking API calls with axios.

### login-test

A custom login form built with React to practice writing tests independently. The form has username and password inputs with controlled state, and the tests check that inputs render correctly, start empty, and handle valid and invalid credentials.

### space-travel

The Space Travel assessment, the final project for the React Testing section. This is a multi-page React app built from a Springboard starter code that simulates an interplanetary evacuation system. Commanders can view and manage a fleet of spacecraft, build new ones, send them to different planets, and decommission old ones.

The app uses React Router for navigation, Formik and Yup for form validation, and a mock API backed by localStorage to simulate a real backend.

Pages included, Home, Spacecrafts, Spacecraft detail, Construction, and Planets.
